# Analgesic Healthcare – Website Redesign Concept

Static design preview (Home, About Us, Contact Us, News, Blog) for client review before the WordPress/Elementor build.

## Publish on GitHub Pages
1. Create a new public repository and upload everything in this folder (keep the `assets` folder structure).
2. Go to **Settings → Pages**, set **Source** to *Deploy from a branch*, branch `main`, folder `/ (root)`, and save.
3. After a minute the site is live at `https://<your-username>.github.io/<repository-name>/`.

Notes: forms are preview-only (they don't send anything). Items marked [Photo] are image placeholders. Pages carry a `noindex` tag so search engines don't list the preview.
